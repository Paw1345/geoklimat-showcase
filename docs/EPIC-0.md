# Product brief

GeoKlimat is a monitoring and discovery tool for environmental and climate
information. It is intended for public-administration staff, GIS specialists,
and environmental teams who need to notice changes across institutional,
regulatory, spatial-data, measurement, and satellite-information sources.

The application brings source status, searchable updates, catalogue metadata,
spatial queries, and selected data workflows together. It favors traceable
original sources, bounded collection, and explicit handling of access and
reuse conditions.

This showcase repository contains application code and synthetic test data. It
does not include the operator's source registry workbook or a production data
snapshot. See [Showcase data policy](SHOWCASE-DATA.md).
